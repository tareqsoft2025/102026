# نظام تقييم الأداء الوظيفي

صفحات ثابتة تعمل على GitHub Pages:

- `index.html`: تسجيل الدخول وإنشاء الحساب (بريد، Google، استعادة كلمة المرور).
- `app.html`: نظام التقييم (مؤشرات، تقييمات، موظفون، دورات، معايير، تقييماتي).
- `core.js`: قاعدة البيانات المحاكاة (localStorage) والحسابات والمنطق المشترك.
- `config.js` و`supabase/schema.sql`: إعداد الخادم الحقيقي (Supabase) لحسابات الدخول.

حسابات تجريبية (كلمة المرور `Demo@12345`): `demo@portal.demo` (مسؤول)، `manager@portal.demo` (مدير)، `employee@portal.demo` (موظف).
